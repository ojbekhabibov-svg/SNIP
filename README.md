# СНиП — Строительные нормы и правила (и пособия к СНиП)

Библиотека СНиП для формирования ППР, ЛРВ и ИТД. Устроена так же, как библиотека ВСН
([ojbekhabibov-svg/VSN](https://github.com/ojbekhabibov-svg/VSN)): оригиналы PDF/HTM, упрощённые тексты,
регистры по направлениям, индекс для Claude.

## Источник

meganorm.ru:
- база 2: [СНиП](https://meganorm.ru/list2/64514-0.htm) (~668), [Пособие к СНиП](https://meganorm.ru/list2/64494-0.htm) (~150), [Пособие в развитие СНиП](https://meganorm.ru/list2/64406-0.htm);
- база 1 (докачка того, чего нет в базе 2): [СНиП](https://meganorm.ru/list1/21-0.htm), [Пособие к СНиП](https://meganorm.ru/list1/41-0.htm), [Пособие в развитие СНиП](https://meganorm.ru/list1/129-0.htm).

## Структура

| Путь | Что |
|---|---|
| `files/` | оригиналы PDF и полнотекстовые HTM (структура папок сайта) |
| `index.csv` | реестр: номер, название, дата, статус, вид (snip/posobie), пути |
| `text/` | упрощённые тексты (шапка, оглавление, чистый текст, метки рисунков) |
| `figures/` | страницы-рисунки из PDF (для документов без HTM) |
| `registers/` | регистры по направлениям (.md), `Реестр_СНиП.xlsx`, `registers.json` |
| `registers/zamena.csv` | замены СНиП → СП (РФ) и аналоги РУз (ШНК/КМК) |
| `registers/classification.csv` | ручные правки направлений (`id;number;directions`) |
| `AI_INDEX.md` | компактный индекс для Claude |

## Порядок сборки (GitHub Actions)

1. **«Скачать СНиП и пособия к СНиП с meganorm.ru»** (`download.yml`) — скачивание; сам перезапускается,
   пока всё не скачано, затем запускает сборку. Если репозиторий заполнится (лимит `max_total_mb`),
   остаток — в `remaining.csv`, докачка в другой репозиторий через `only_ids`.
2. **«Регистры СНиП»** (`build.yml`) — OCR PDF без HTM, упрощённые тексты, регистры, AI_INDEX.

## Применение в РУз

Статусы и замены на СП — по данным РФ. В Узбекистане сначала действует ШНК/КМК; СНиП применяется,
если национального документа нет или на СНиП есть ссылка в РД. Аналоги РУз ведутся в `registers/zamena.csv`
(столбец `uz`) — дополняется по мере подтверждения.
